Build temporal Context Graphs with the open-source Graphiti framework
Want to use Graphiti with AI assistants like Claude Desktop or Cursor? Check out the Graphiti MCP Server .
Graphiti is the open-source framework for building temporal knowledge graphs —
Context Graphs — that power Zep. It incrementally updates graphs as new
episodes arrive, so relationships and facts can evolve with the source data.
